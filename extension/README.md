# Career Copilot Autofill (Chrome extension)

Fills job application forms (Greenhouse, Lever, Ashby, Workable, SmartRecruiters, Workday) with the answers and the Resume Studio PDF prepared in Career Copilot. **It never submits.** You review the form, tick consent boxes yourself and press Submit.

## Install (once)
1. Chrome → `chrome://extensions` → turn on **Developer mode** → **Load unpacked** → choose this `extension` folder.
2. In Career Copilot: Apply queue → 🧭 Guided → Autofill setup → **Create autofill key**.
3. Click the extension icon, paste the key, **Save & test** (should say ✓ Connected).

## Use
Open an application from the Apply queue, click **⚡ Fill with Career Copilot** (bottom-left).
Green = filled, amber = check it, red = required and needs you. Then Submit, then ✓ Applied in the app.

The key only reads your prepared answers and resume PDF. Creating a new key retires the old one.
